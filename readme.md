# Kernel compile workflow (for personal usage)
# By Sarthak Roy (sarthakroy2002@gmail.com)

## How to use
1. Fork the repository.
2. Go to the Actions tab in your forked repository.
3. Select the workflow and input the necessary parameters:
   - Kernel version: Choose the version of the kernel to compile.
   - Configuration file: Upload a `.config` file if needed.
4. Start the workflow, and once completed, the kernel image (`Image.gz`) will be generated as an artifact.
